# 2026-09-04 Production Hotfix

## Release note

- Fixed stale tournament data and deletion so removed events cannot be reopened from local cache.
- Added pool size and advancing-team controls for tournament setup.
- Improved live sync and score correction workflow by writing score reports back to canonical tournament state.
- Moved key live and score actions higher in the manager and player UI.

## Manual QA checklist

1. Compass stale roster case
   - On one browser/device, open `players.html?event=Compass` after previously viewing an old Compass event.
   - Expected: the roster shown matches the current canonical event state, including the current 13-team roster. Old names such as `Hello` and `Fred` do not appear unless they are in the current event.

2. practicemakesperfect contamination case
   - Create a brand-new tournament with one-word code `practicemakesperfect`.
   - Expected: the roster starts empty. No players, pools, matches, standings, score reports, bracket entries, or stranded players carry over from another tournament.

3. Delete means delete
   - Log in as manager, choose the delete/reset action, and confirm.
   - Reload the manager page and try the same event word in the player portal.
   - Expected: the event cannot be opened, local tournament keys are cleared, and no deleted players/matches reappear.

4. Phone submit vs laptop sync
   - Open manager Pool Play on a laptop and the Player Portal on a phone for the same event.
   - Submit a score from Team A, then submit the same score from Team B.
   - Expected: manager Pool Play and Standings update after the score reports converge. The match shows as final, standings totals recompute, and the Live badge remains visible at the top.

5. Manager correction path
   - From manager Pool Play, use Correct on a final score and enter a different valid score.
   - Expected: the corrected score replaces the old final, standings recompute from all confirmed matches, and connected player/spectator views refresh.

6. Configurable pool size
   - Create or open a 10-team tournament, set Pool Size to 5, and generate pools.
   - Expected: two 5-team pools are created and pool schedules follow those assignments.

7. Configurable advancing teams
   - Create or open a 9-team tournament, set Teams Advancing to 4, then seed the bracket.
   - Expected: the bracket starts at semifinals with 4 teams. It does not create an all-advance Round of 16.

8. UX placement
   - Open the manager page.
   - Expected: the Live/Not Live indicator is visible at the top-right of the manager viewport.
   - Open the player portal.
   - Expected: Submit a match score appears near the top, directly after tournament selection and before rules/lower content.
